# 底値ごはん

値札やレシートから、自分の生活圏の底値を覚える。今週の食費を入れると、その予算のなかで栄養が偏らない献立と、店ごとの買い物リストを出す。

オンラインの価格比較は残る。実店舗の生鮮と食品は、自分で撮った値段が帳面になる。

## できること

- 生活圏（中野坂上・下北沢・西葛西）の見本相場と、8週の底値
- 値札・レシートの記録。サンプルのレシートで、底値が更新されるところまで試せる
- 買い時、見送り、特売曜日の通知
- 「今週の食費 5,000円」から、朝と夜の献立。金額だけの最安案と、栄養を戻した案を並べる
- いちばん安い店への振り分けと、1店にまとめたときの差額
- 価格予測はプレミアムの見本。店への送客も、在庫とはつながっていない見本

記録はこのブラウザの中だけに残る。アカウントはない。

## 起動

```bash
npm install
npm run dev
```

開発サーバは [http://127.0.0.1:43123](http://127.0.0.1:43123) で開く。

```bash
npm test
npm run lint
```

献立の計算と、特売が中央値を下回ることの確認は `npm test`。
