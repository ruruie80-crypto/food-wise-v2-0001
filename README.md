# 底値ごはん

食品の底値を記録して、安い食材から献立を考えるためのWebアプリです。

## できること

- 値札やレシートをスキャンして価格を記録
- 商品ごとの底値を一覧・比較
- 底値の食材から献立を提案
- 買い物リストの管理
- 値下がりの通知

## 使い方

1. 「スキャン」から価格を記録する
2. 「底値」で商品ごとの最安値を確認する
3. 「献立」で提案を見る
4. 「買う」で買い物リストを作る

## 使った技術

- Next.js / TypeScript
- Tailwind CSS
- Vercel（公開）
- Cursor（AI支援で開発）

## 作った背景

毎日の買い物で「これは高いのか安いのか」が分からず、記録も続かないのが不便でした。
値札をスキャンするだけで底値がたまり、自然と安い食材で献立が組めるようにしたくて作りました。

## 公開してよい境界

このリポジトリは、その前提のまま公開できます。

オンラインの価格比較は残しています。実店舗の生鮮は、自分で読んだ値段が帳面になる、という前提です。

- 東京（中野坂上・下北沢・西葛西）の店名と値段は見本です。実在の店の在庫や本日の売価ではありません。
- 宮城県（仙台・岩沼・石巻・大崎）の店は、ヨークベニマル、フレスコキクチ、イオン、みやぎ生協の実在店舗です。岩沼はヨークベニマル岩沼店・岩沼西店、フレスコキクチ岩沼西店・岩沼東店、みやぎ生協岩沼店です。献立に使う値段は、総務省統計局の小売物価統計調査（仙台市・2026年8月）を単位換算した市内平均です。岩沼・石巻・大崎には市ごとの統計表がないため、仙台市の数字を使っています。
- ホームの「きょうの仙台市場」は、仙台市中央卸売市場の青果日報（開市日に更新）です。卸売価格で、スーパーの棚の売価ではありません。旬は東北農政局の仙台周辺の表です。
- アカウントはありません。予算、献立、値札はこのブラウザの中だけに残ります。
- カメラはこのサイトを開いているときだけ使えます。写真は保存も送信もしません。サンプルのレシートで最後まで試せます。
- 価格予測と店への案内は画面の見本です。決済も在庫もつながっていません。
- 栄養は予算と比べるための目安で、医療上の指導ではありません。
- 画面の着せ替え（紙の帳面、夜のスーパー、赤提灯、朝の八百屋）はこのブラウザに残ります。夜店の背景は金魚、提灯は画面の上に掛かる赤い提灯の列、八百屋は野菜です。提灯は帳面のカードや文字の下には出しません。献立と値札は変わりません。
- 献立と値札は、自分で書き出した Zip（メモと記録）として渡せます。アプリが相手へ送ることはありません。

秘密情報は置いていません。外部の API キーも不要です。

npm install
npm run dev
```

開発サーバは [http://127.0.0.1:43123](http://127.0.0.1:43123) で開きます。

npm test
npm run lint
```
